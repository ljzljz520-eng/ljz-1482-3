# 博物馆导览制作间（Museum Guide Studio）

网页上编辑展品讲述与路线、后端管理音频处理任务、数据库关联展品事实 / 多语言版本 /
儿童·普通·专家三种文稿的一体化制作与发布系统。**仅依赖 Python 3 标准库（http.server + sqlite3），
无需安装任何第三方包。**

## 运行

```bash
./run.sh                          # 初始化演示库并启动，打开 http://127.0.0.1:8070
python3 tests/test_acceptance.py  # 47 项端到端验收
```

| 路径 | 作用 |

| `backend/seed.py` | 演示数据：3 展品、共享事实、中/英/日 × 三受众文稿 |

| `tests/test_acceptance.py` | 题目全部验收场景 |

## 核心不变量（设计如何对应需求）

### 1. 共享事实修订 → 待复核，但措辞/语速不被覆盖
事实（fact）语言中立，被各语言、各受众文稿多对多引用（manuscript_fact）。
修订事实只做两件事：事实版本 +1、把引用它的全部文稿状态置为 pending_review。
segment.text（措辞）与 rate_wpm（语速）绝不写入、不覆盖。各语言文稿必须人工分别
「复核通过」——中文更新不会让英文自动通过。

### 2. 稳定片段身份，改一句只重做受影响部分
一句话一个稳定身份 seg:{文稿id}#序号，序号身份在改稿后不变；正文变化只改 content_hash。
音频/字幕/脚本资产按 (稳定身份, 内容哈希, 语速, 音色) 寻址缓存。改一句话只令该句一个
任务缓存未命中，其余句命中；迟到的旧哈希任务自动标记 superseded，任务乱序完成安全。
路线时长随片段重渲染自动重算（Σ解说音频 + 驻留 + 转场）。

### 3. 整段重生成 vs 分段拼接（音频任务页“对比”按钮）
- 音色连续性：整段整篇一次合成，呼吸与跨句语调自然，连续性最好；分段在句边界约 120ms
  韵律间隔，音色同源但句调独立，长段可能有拼接感。
- 缓存：分段按句缓存，改一句/调一档语速只失效 1 句；整段粒度是整篇，任意改动全篇失效。
- 成本：首版相同；改一句后分段按 1/n 句计费（可并行、可 CDN 缓存），整段按全篇计费。
  建议常规生产用分段（迭代省钱、多语速友好），重点展项用整段重渲做质量兜底（双轨 A/B）。

### 4. 展品临时撤展 → 可达顺序重验证
撤展不允许「只删卡片」：前一张卡的转场指路音频仍会把观众带到空展柜。任何撤展/悬空卡
都判为问题（连续撤展点为“可达顺序断裂”），路线置 invalid 且不可发布，必须重排
（移除或替换、重建转场指路）后才恢复 valid。

### 5. 两人改路线
路线带单调 version，提交带 base_version（乐观锁）。后提交者若基于旧版本 → HTTP 409
冲突，必须先拉取最新版合并，后提交不会静默覆盖先提交。

### 6. 版本间依赖缺口与发布门禁（只有闭包满足才能发布）
每个导览包按语言独立做资料闭包检查，缺口逐项列在网页「闭包报告」：路线可达、该语言
三受众文稿全部 approved、每片段 audio/subtitle/script 齐备、展品图片授权未到期、
转场指路齐备。中文已更新而外语未复核时，中文包可发布、外语包 blocked；被阻断也占用
一个语义化版本号，版本不回退。

### 7. 现场离线包：明确版本 + 更新状态 + 断点续传
导出为多步流水线（校验→冻结清单→逐资产→转码→建索引→签名→写更新标记），每步幂等
并记录进度；中断状态 interrupted，续传跳过已完成步骤。落地的离线包 JSON 自描述
semver / offline / update_state(fresh_install|up_to_date|update_available) /
from_version / 资产哈希清单，设备据此显示明确版本与更新状态。

## 验收场景（tests/test_acceptance.py，47 项）
1. 事实修订后 9 篇文稿进入待复核、外语措辞与语速不变、逐语言复核
2. 任务乱序完成、幂等去重、改一句只重做该句三类资产、旧任务 superseded、路线时长重算
3. 整段 vs 分段的连续性/缓存/成本量化对比
4. 撤展后路线 invalid、识别“音频指路到空柜”、重排恢复、连续撤展断裂
5. 两人改路线 409 冲突、先提交不被覆盖、合并后成功
6. E002 图片授权 2026-03-01 已到期 → 闭包缺口、禁止发布
7. 中文闭包 ready 可发布、英文包 blocked（未复核 + 缺资产）
8. 导出中断 → 断点续传 → 离线包含明确版本/更新状态/资产哈希
